# java-racingcar-precourse
### 1. 자동차 이름 입력
-   쉼표(,)로 구분된 자동차 이름을 입력받는다. (이름은 5자 이하)
-   경주를 시도할 횟수(숫자)를 입력받는다.

### 2. 게임
-   각 자동차는 0에서 9 사이의 무작위 값을 구한다.
-   무작위 값이 4 이상일 경우 1칸 전진하고, 3 이하일 경우 멈춘다.
-   입력된 시도 횟수만큼 모든 자동차의 전진/멈춤을 반복한다.

### 3. 우승자 출력
-   각 실행 횟수(라운드)마다 모든 자동차의 이름과 현재 위치를 출력한다.
    -   (예: `pobi : --`)
-   게임 종료 후, 가장 많이 전진한 자동차를 우승자로 선정하여 출력한다.
-   우승자가 여러 명일 경우 쉼표),(로 구분하여 모두 출력한다.
    -   (예: `최종 우승자 : pobi, woni`)

### 4. 예외 처리
-   사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시키고 애플리케이션을 종료한다.
    -   (예: 자동차 이름 5자 초과, 이름 공백, 시도 횟수가 숫자가 아니거나 1 미만인 경우 등)
